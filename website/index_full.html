Frequently Asked Questions.

Does Squeeze alter the accuracy of LLM responses?

No. Squeeze uses content-aware structural compression (JSON schema conversion, AST code signature preservation) and CCR local caching so essential key information is never lost.

How does CCR (Reversible Compression) work?

CCR caches raw uncompressed chunks on your local machine using short hash IDs (`[CCR:sq_ref_123]`). If an LLM needs exact source details, it calls `squeeze_retrieve` to pull back the uncompressed content on demand.

Is my data sent to any third-party server?

Never. Squeeze runs 100% locally on your machine — as a local Node.js proxy (`localhost:8787`) or browser WebExtension. Your data never leaves your environment.

How do I wrap Claude Code or Cursor?

Simply run `squeeze proxy` in one terminal window, then launch your agent with `squeeze wrap claude` or `squeeze wrap cursor`. It automatically proxies network calls through Squeeze.
