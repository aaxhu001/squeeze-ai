Global Installation & Setup

One global install; setup command auto-registers Squeeze across all your local AI tools.

npm install -g squeeze-ai
squeeze-ai mcp setup

Available CLI tools: squeeze-ai compress · squeeze-ai doctor · squeeze-ai stats

Claude Desktop & Claude Code

Run this command in your terminal to auto-inject Squeeze into claude_desktop_config.json:

squeeze mcp setup

Or if running from repository root:

node bin/squeeze.js mcp setup

Connected tools: squeeze_compress · squeeze_retrieve · squeeze_stats · squeeze_doctor

Add to Cursor IDE

Run squeeze mcp setup or paste into .cursor/mcp.json at your project root:

{ "mcpServers": { "squeeze": { "command": "squeeze", "args": ["mcp"] } } }

Add to VS Code / Continue / Roo Code

Command Palette ➔ MCP: Add Server ➔ paste the command below:

squeeze mcp

Or run squeeze mcp setup to auto-configure all VS Code extensions.

Raw MCP Protocol / Transport

Standard JSON-RPC over stdio for any custom MCP client:

{ "mcpServers": { "squeeze": { "command": "npx", "args": ["-y", "squeeze-ai", "mcp"] } } }

For background servers or remote agents, launch the MCP SSE HTTP transport:

npx -y squeeze-ai mcp serve --port 8788

Is Squeeze really 100% local and private?

Yes. Squeeze runs entirely on your local computer. Your code, prompts, logs, and JSON data are processed locally and never sent to any external server or third-party cloud.

How does Squeeze help with Claude message limits?

Claude calculates usage based on total tokens sent. By compressing repetitive code, JSON, and polite filler by up to 99%, Squeeze lets you send many more messages before hitting limits.

What happens if Squeeze removes something the AI needs?

Nothing is permanently lost. Squeeze stores a copy of every trimmed block in your local Context Vault. If the AI ever needs the exact original, you pull it back with a single bookmark call.

How do I set up Squeeze with Cursor or VS Code?

Setup takes less than 60 seconds. Simply run squeeze mcp setup in your terminal or point Cursor's API base URL to http://localhost:8787/v1.

Does Squeeze work with ChatGPT and Gemini?

Yes. Squeeze works universally across Claude.ai, ChatGPT, Google Gemini, Cursor IDE, and any custom API integration using the Model Context Protocol (MCP).

How do I install and connect Squeeze via MCP?

Simply run npx squeeze-ai mcp setup in your terminal. It automatically configures your claude_desktop_config.json or Cursor .mcp.json file.
