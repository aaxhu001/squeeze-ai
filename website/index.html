INSTALLATION GUIDE

Connect Squeeze to your workflow

Select your AI model, IDE, or developer tool below to view instant setup instructions.

1. Auto-configure Claude Desktop
One command registers Squeeze in your claude_desktop_config.json file.
npx squeeze-ai init --client claude-desktop --write
2. Or write the project config manually
Add Squeeze under mcpServers in %APPDATA%\Claude\claude_desktop_config.json:
{
  "mcpServers": {
    "squeeze": {
      "command": "node",
      "args": ["C:/AASHU DEVS/Squeeze/version2/mcp-server.js"]
    }
  }
}
3. Verify connection
Restart Claude Desktop ➔ Open Settings ➔ Developer and confirm squeeze shows as connected.
1. Add Squeeze MCP to Claude Code
Run the command below in your terminal to register the server.
claude mcp add squeeze node "C:/AASHU DEVS/Squeeze/version2/mcp-server.js"
2. Verify connection
Run claude mcp list and confirm Squeeze shows as connected.
claude mcp list
1. Open Extensions Page
Open Google Chrome or Edge and navigate to chrome://extensions.
2. Enable Developer Mode
Toggle the Developer mode switch in the top-right corner.
3. Load Unpacked Extension
Click Load unpacked and select the directory:
C:\AASHU DEVS\Squeeze\version2
1. Start Squeeze Local Proxy
Run Squeeze proxy in your terminal to intercept LLM API payloads:
npx squeeze proxy --port 8080
2. Update Cursor Model Base URL
In Cursor Settings ➔ Models ➔ OpenAI/Anthropic Base URL, set:
http://localhost:8080/v1
1. Install Squeeze CLI globally
Install Squeeze via npm to run prompt optimization from your terminal:
npm install -g squeeze-ai && squeeze --version
1. Install Squeeze SDK
Integrate Squeeze context trimming into Node.js or Python agent pipelines:
npm install squeeze-ai   # Node.js / TypeScript
pip install squeeze-ai   # Python
1. Start Squeeze Stdio Server
Use the Squeeze stdio MCP server in any custom MCP client host:
npx squeeze mcp serve --stdio

HOW IT WORKS

Engineered to eliminate context bloat

Squeeze strips redundant tokens before they reach your AI model, saving context window memory and lowering API costs.

100% Client-Side Local Execution

Your code and prompts never touch third-party servers. All regex, AST tokenization, and payload trimming execute locally on your machine inside WebAssembly & local proxy loops.

// Executed locally in memory (0ms network latency):
✓ Security Verified: Zero cloud data transmission
✓ Compatible with SOC2 & enterprise privacy policies

Automated Filler Stripping

Instantly removes conversational pleasantries, redundant intros ("Hey Claude!"), and verbose fluff without altering core prompt instructions.

- "Hey Claude, hope you're doing well! Could you please..."
+ "Review React dashboard component for bugs:"

JSON & Payload Trimming

Squeezes bulky API responses, database logs, and JSON context files down by 60–95% while keeping key data structures perfectly readable for LLMs.

⚡ 60-95% Token Reduction on API Payloads

Intelligent Code Deduplication

Stop resending thousands of lines of unchanged source code in long multi-turn chats. Squeeze detects cached code fragments and replaces duplicate blocks with lightweight reference hashes.

// Multi-turn chat optimization:
- [2,400 lines of unchanged React dashboard code copy-pasted again]
+ // [Cached block ref: #dashboard_v3 - 2,400 lines unchanged]
