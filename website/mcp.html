Squeeze MCP — Context Compression for AI Coding Agents

Connect Cursor, Claude Code, Claude Desktop, Windsurf, or any MCP client to the Squeeze engine: search & compress prompts, JSON payloads, and source code without leaving your editor.

1. Add Squeeze MCP to Claude Code
Run the command below in your terminal to register the Squeeze MCP server.
claude mcp add --transport http squeeze https://squeeze.ai/api/mcp --header "x-api-key: $API_KEY_SQUEEZE"
2. Or write the project config
One command writes .mcp.json for you.
npx @squeeze-ai/cli init --client claude --write
3. Verify connection
Run claude mcp list and confirm squeeze shows as connected.
4. Or install everything as a plugin
One install bundles the MCP server above with the Squeeze skills from the terminal.
/plugin marketplace add squeeze/claude-code-plugin
/plugin install squeeze@squeeze
1. Auto-configure Claude Desktop
One command registers Squeeze in your claude_desktop_config.json file.
npx squeeze-ai init --client claude-desktop --write
2. Or write the project config manually
Add Squeeze under mcpServers in %APPDATA%\Claude\claude_desktop_config.json:
{
  "mcpServers": {
    "squeeze": {
      "command": "node",
      "args": ["C:/AASHU DEVS/Squeeze/version2/mcp-server.js"]
    }
  }
}
1. Connect Squeeze to OpenAI / Codex
Run Squeeze local proxy to intercept OpenAI API calls:
npx squeeze proxy --target openai
1. Start Squeeze Local Proxy
Run Squeeze proxy in your terminal to intercept LLM API payloads:
npx squeeze proxy --port 8080
2. Update Cursor Model Base URL
In Cursor Settings ➔ Models ➔ OpenAI/Anthropic Base URL, set:
http://localhost:8080/v1
1. Install Squeeze CLI globally
Install Squeeze via npm to run prompt optimization from your terminal:
npm install -g squeeze-ai && squeeze --version
1. Install Squeeze SDK
Integrate Squeeze context trimming into Node.js or Python agent pipelines:
npm install squeeze-ai   # Node.js / TypeScript
pip install squeeze-ai   # Python
1. Start Squeeze Stdio Server
Use the Squeeze stdio MCP server in any custom MCP client host:
npx squeeze mcp serve --stdio
MCP TOOLS CATALOG

Built for AI Agents & Editors

Squeeze exposes native MCP tools for Claude Code, Cursor, and VS Code. Search & invoke tools directly in your editor.

squeeze_trim Core Tool
String Trim

Trims greetings ("Hey Claude"), conversational fluff, and pleasantries automatically before sending prompts to the LLM.

squeeze_trim({ prompt: string, mode: "squeeze"|"balanced" })
squeeze_json Payload
60-95% Savings

Compresses bulky JSON API responses, database logs, and schema context files while keeping data structures fully valid.

squeeze_json({ payload: object, flatten: true })
squeeze_dedup Code AST
Multi-Turn

Replaces previously copy-pasted source code blocks across multi-turn chats with lightweight reference hashes.

squeeze_dedup({ threadId: string, code: string })
squeeze_proxy Localhost
Cursor / VS Code

Launches a zero-latency local HTTP proxy on http://localhost:8080 for seamless IDE integration.

squeeze_proxy({ port: 8080, target: "claude" })
squeeze_prompt System Prompt
LLM Instructions

Generates a master Squeeze system prompt instruction block for ChatGPT, Claude web, or Gemini models.

squeeze_prompt({ targetModel: "claude-sonnet-5" })
squeeze_ast Parser
TypeScript / JS

Performs AST-based syntax whitespace compression and comment stripping for source code files.

squeeze_ast({ code: string, stripComments: true })
