Connect Squeeze to your workflow

Select your AI model, IDE, or developer tool below to view instant setup commands.

1. Add Squeeze MCP to Claude Code
Run the command below in your terminal to register the server.
claude mcp add --transport http squeeze https://squeeze.ai/api/mcp --header "x-api-key: $API_KEY_SQUEEZE"
2. Or write the project config
One command writes .mcp.json for you.
npx squeeze-ai init --client claude --write
3. Verify connection
Run claude mcp list and confirm Squeeze shows as connected.
4. Or install everything as a plugin
One install bundles the MCP server above with the Squeeze skills (search/get/add/publish from the terminal).
/plugin marketplace add squeeze/claude-code-plugin
/plugin install squeeze@squeeze
1. Auto-configure Claude Desktop
One command registers Squeeze in your claude_desktop_config.json file.
npx squeeze-ai init --client claude-desktop --write
2. Verify connection
Restart Claude Desktop ➔ Open Settings ➔ Developer and confirm squeeze shows as connected.
1. Install Squeeze CLI globally
Install Squeeze via npm to run prompt optimization from your terminal:
npm install -g squeeze-ai && squeeze --version
1. Connect Squeeze to OpenAI Codex / GPT-4o
Run Squeeze local proxy server:
npx squeeze proxy --port 8080
1. Start Squeeze Local Proxy
In Cursor Settings ➔ Models ➔ OpenAI/Anthropic Base URL, set:
http://localhost:8080/v1
1. Integrate Squeeze SDK
Install Squeeze SDK in your Lovable project:
npm install squeeze-ai
1. Start Squeeze MCP Stdio Server
Use the Squeeze stdio MCP server in any custom MCP client host:
npx squeeze mcp serve --stdio
